# How It Works

This repository follows a simple flow:

```text
Idea
  ↓
Issue
  ↓
Discussion
  ↓
Pull Request
  ↓
Merge
  ↓
Live Feature
```

## Step-by-step in plain language

1. **Idea**  
   A customer or business need appears.

2. **Issue**  
   The PM creates a feature request describing the problem and desired outcome.

3. **Discussion**  
   PM, design, and engineering align on scope, risks, and trade-offs.

4. **Pull Request**  
   Engineering proposes implementation. PM reviews for product intent.

5. **Merge**  
   Team approves and accepts the change.

6. **Live Feature**  
   Feature is released, measured, and learned from.

This keeps work transparent and collaborative without heavy process.
