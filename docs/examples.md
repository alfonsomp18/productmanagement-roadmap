# Examples for Product Managers

## Example 1: Creating a feature request

**Scenario:** You want to improve onboarding completion.

1. Go to **Issues** in GitHub.
2. Click **New issue**.
3. Choose **Feature request** template.
4. Fill in:
   - What problem are we solving?
   - Who is this for?
   - Proposed solution
   - Success criteria
   - Priority
5. Link the initiative (for example: `customer-activation-excellence.md`).
6. Add labels and a milestone.
7. Save the issue.

Result: your idea is now visible, discussable, and trackable.

---

## Example 2: Approving a feature

**Scenario:** Engineering proposes a change for your feature issue.

1. Open the linked **Pull Request**.
2. Read the summary in plain language.
3. Confirm it solves the original problem.
4. Ask for changes if anything is unclear.
5. Approve when ready.
6. After merge, mark the issue as done.

Result: PR approval becomes a lightweight product sign-off step.

---

## Example 3: Planning a quarter

**Scenario:** You are planning Q3 priorities.

1. Review `roadmap/next.md`.
2. Choose top initiatives by business impact.
3. Move related feature issues into milestone **Q3-2026**.
4. Set status labels to `status:planned`.
5. Add issues to the project board column **Planned**.
6. During execution, move to **In Progress** and update `roadmap/now.md`.

Result: strategy, roadmap, and execution stay connected.
